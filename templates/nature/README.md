# Nature Template

用于 Nature 系列期刊（Nature, Nature Communications, Scientific Reports 等）。

## 特点
- 摘要宽度限制 150 字
- 正文 2000-4000 字
- 方法在正文后
- 最多 6 张图
- 数字引用 (numeric)
- 作者贡献声明
- 数据可用性声明
- 利益冲突声明

## 基本结构
```
摘要 (<150字)
引言/背景
结果
讨论
方法
数据可用性
代码可用性
参考文献
致谢
作者信息
作者贡献
竞争利益声明
补充信息
```

# ACM Template

用于 ACM 会议/期刊论文。

## 文件
- `main.tex` — 主文件，使用 `acmart` 文档类
- `acmart.cls` — ACM 官方文档类

## 基本结构
```latex
\documentclass[sigconf]{acmart}
% sigconf: 双栏会议格式
% acmsmall: 单栏小期刊格式
% acmlarge: 单栏大期刊格式
```

## 特点
- CCS 概念分类要求
- 数字引用 (numeric citation style)
- 作者 ORCID 标识
- 资助声明
- 最多 20 张图表

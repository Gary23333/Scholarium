# IEEE Template

用于 IEEE 会议/期刊论文。

## 文件
- `main.tex` — 主文件，使用 `IEEEtran` 文档类
- `ieee.cls` 或 `IEEEtran.cls` — IEEE 官方文档类（需从 IEEE 网站下载）

## 基本结构
```latex
\documentclass[conference]{IEEEtran}
% 或
\documentclass[journal]{IEEEtran}
```

## 特点
- 双栏布局
- 数字引用 (numeric citation style)
- 强制 IEEE metadata（作者、机构、ORCID）
- 最多 15 张图表
- 8 页限制（会议）

## 资源

# Elsevier Template

用于 Elsevier 期刊论文（如 Computers & Education, Pattern Recognition 等）。

## 文件
- `main.tex` — 主文件，使用 `elsarticle` 文档类
- `elsarticle.cls` — Elsevier 官方文档类

## 基本结构
```latex
\documentclass[review]{elsarticle}
% review: 双栏审稿格式
% final: 单栏最终格式
% 1p: 单列格式
```

## 特点
- APA/作者-年份引用
- 研究亮点 (Highlights)
- 图形摘要 (Graphical Abstract)
- 作者贡献声明 (CRediT)
- 数据可用性声明
- 冲突声明

# Springer Template

用于 Springer 期刊/会议论文（Lecture Notes in Computer Science 等系列）。

## 文件
- `main.tex` — 主文件，使用 `svjour3` 或 `llncs` 文档类
- `svjour3.cls` — Springer 期刊文档类
- `llncs.cls` — LNCS 会议论文文档类

## 基本结构
```latex
\documentclass[twocolumn]{svjour3}
% 或
\documentclass{llncs}
```

## 特点
- 作者-年份引用 (author-year for journals)
- ORCID 标识
- 伦理声明
- 数据可用性声明
- 单栏或双栏可选

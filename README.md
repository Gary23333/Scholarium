## 为什么是 Scholarium？

大多数 AI 写作工具只做一件事：**生成文本**。Scholarium 做的是一整条学术流水线——

```
研究方向 ──→ 苏格拉底 5 层追问 ──→ 思维导图 3 轮发散 ──→ 大纲
                                                              │
    LaTeX PDF ←── 编译 ←── 修订 ←── 7 代理同行评审 ←── 18 维审计 ←── 逐节写作
```

不是"帮你写一段话"，而是 **23 个专用 Agent 各司其职**，像一支真正的学术团队：

| | Agent | 做什么 |
|---|---|---|
| 🎯 | **SocraticMentor** | 5 层苏格拉底追问，逼你想清楚到底要研究什么 |
| 🗺️ | **Cartographer** | 3 轮思维导图发散，从 30+ 分支中锁定创新点 |
| ✍️ | **Writer** + **Architect** + **Composer** | 蓝图→上下文→正文，逐段生成 LaTeX |
| 🔍 | **Auditor** | 18 维质量审计：逻辑/引用/术语/数据/数学/结构… |
| 🛡️ | **Anti-AI** | 6 维 AI 痕迹检测 + 智能改写，让文本更像人写的 |
| 👥 | **7 位评审 Agent** | 主编 + 3 审稿人 + 魔鬼代言人，模拟真实同行评审 |
| 📚 | **Librarian** | 多源文献搜索 + 引用真实性验证 |
| 🔭 | **Radar** | 10 个顶会/顶刊画像，推荐最佳投稿目标 |

**反幻觉 7 层防护**贯穿全程：温度分层 → 引用前置 → 引用强校验 → Bible 记忆 → 输入治理 → 18 维审计 → 受保护内容检查。

### ✍️ Step 2 — 摘要 & 引言写作

Writer Agent 生成的 LaTeX 正文（节选）：

> **摘要**
>
> Large language models have demonstrated remarkable proficiency in generating fluent academic prose, yet their propensity to produce hallucinated content—plausible but factually incorrect statements—poses a significant threat to scholarly integrity. This paper addresses the critical challenge of detecting and mitigating hallucinations in academic writing generated by these models. We propose a novel multi-agent framework that systematically identifies and corrects hallucinated content through three complementary mechanisms: **factual grounding** against authoritative knowledge bases, **citation verification** to ensure referenced sources genuinely support the claims, and **iterative self-correction** where the model refines its output based on feedback from the detection agents. […] Experimental results demonstrate that our framework reduces hallucination rates by over forty percent compared to baseline generation, while preserving the fluency and coherence of the original text.

> **引言（节选）**
>
> 近年来，以 GPT-4、Claude 和 Llama 为代表的大语言模型在学术写作辅助领域展现出前所未有的潜力，能够协助研究者完成文献综述、方法描述、结果讨论乃至全文初稿的生成。然而，随着这些模型在科研工作流中的深度渗透，一个严峻的问题日益凸显：**幻觉（hallucination）**——即模型生成看似合理但事实错误、无中生有或与上下文矛盾的内容。在学术写作这一对准确性和可追溯性要求极高的场景中，幻觉不仅会误导读者，更可能侵蚀科学研究的可信度基础。
>
> ……本文提出一种面向学术写作场景的**三层防御框架**（Three-Layer Defense Framework），旨在系统性地检测并缓解大语言模型在学术写作中产生的幻觉。该框架的核心设计理念是"由外而内、层层递进"：
> - **第一层：事实锚定**（Factual Grounding）— 将关键论断与可信外部知识源进行语义对齐
> - **第二层：引用验证**（Citation Verification）— 逐条核查引用的真实性与语义一致性
> - **第三层：迭代自校正**（Iterative Self-Correction）— 多轮生成-验证-修正循环

### 🔍 Step 3 — 18 维质量审计

Auditor Agent 对上述内容自动执行 18 维审计，输出结构化评分：

| 维度 | 分数 | 审计意见 |
|------|:----:|----------|
| 结构合理性 | **9** | 摘要结构完整，引言层次分明 |
| 贡献明确性 | **9** | 三点贡献清晰，分别对应框架、指标、实验 |
| 逻辑连贯性 | **8** | 从问题到方案层层递进，结构连贯 |
| 术语一致性 | **8** | 核心术语使用一致 |
| 语言质量 | **8** | 学术表达准确流畅 |
| 创新对齐度 | **8** | 三层框架具有明确创新性 |
| 可读性 | **8** | 通俗易懂，部分术语需解释 |
| 引用完整性 | **7** | 数量充足，部分引用需核实 |
| 跨节一致性 | **7** | 摘要与引言中框架名称需统一 |
| 论证完备性 | **7** | 未充分讨论框架局限性 |
| 数据准确性 | **6** | 数据声明需补充实验细节 |
| 声明证据链 | **6** | 多项声明缺乏具体来源 |

> ⚠️ **关键问题**：摘要中"多智能体框架"与引言中"三层防御框架"术语不一致；部分引用可能为虚构；数据声明需补充来源。

### 👥 Step 4 — 7 代理同行评审

Editor-in-Chief Agent 模拟主编决策：

> **总体评价**：选题具有重要的理论价值和现实意义。论文结构完整，实验设计较为系统。然而，在方法创新性、实验严谨性和学术贡献的独特性方面仍存在若干值得商榷之处。
>
> **主要优点**：
> 1. 问题定位准确，动机充分——清晰阐述了学术写作中幻觉的独特危害性
> 2. 框架设计具有系统性——引用意图分类机制在现有文献中较为少见
> 3. 评估体系较为全面——四维度指标 + 人工标注评测数据集
>
> **主要问题**：
> 1. 技术细节和实现路径披露不足，可复现性存疑
> 2. 基线比较的公平性需进一步说明，统计显著性未报告
> 3. 迭代自校正的贡献分析存在检测层误差传播的潜在混淆
>
> 📌 **编辑决策：Major Revision**

### 🛡️ Step 5 — 6 维 AI 痕迹检测

Anti-AI Agent 对生成文本进行"去 AI 化"检测：

| 维度 | AI 概率 | 证据 |
|------|:-------:|------|
| 句法复杂度 | **90%** | 句子结构高度规整，缺乏人类写作中的句式变化 |
| 风格一致性 | **90%** | 全文语气高度统一，缺乏个性化表达 |
| 语义连贯性 | **85%** | 过度依赖连接词，段落衔接过于平滑 |
| 词汇多样性 | **80%** | 频繁使用"显著""严峻"等高频安全词汇 |
| 领域特异性 | **80%** | 术语使用较表面，缺乏领域深度 |
| 信息密度 | **75%** | 部分段落存在信息稀释和冗余 |
| **综合判定** | **85%** | `ai-generated` → 触发智能改写流程 |

> 检测到 AI 痕迹后，Anti-AI Rewriter 会自动执行规则/LLM 双模式改写，降低 AI 概率至阈值以下。

## 🚀 5 分钟快速启动

```bash
# 克隆
git clone https://github.com/Gary23333/Scholarium.git && cd Scholarium

# 安装
npm ci
cd frontend && npm ci && npm run build && cd ..

# 配置（可选，未配置时使用规则模式）
export DEEPSEEK_API_KEY=sk-xxxxxxxx

# 启动
npm run serve

# 打开
open http://localhost:3456
```

**无需 GPU，纯 CPU 运行。** 只需 Node.js 22+ 和一个 LLM API Key。

## 🏗️ 系统架构

```
研究方向输入
  │
  ├─ Stage 0 ─ 苏格拉底 5 层对话引导
  │   问题框架 → 方法论反思 → 证据推理 → 观点评估 → 影响后果
  │
  ├─ Stage 1 ─ 思维导图 3 轮发散
  │   广度分支 → 深度子话题 → Gap / Novelty 定位
  │
  ├─ Stage 2 ─ 逐节写作管道（10 子阶段）
  │   Planner → Architect → Composer → Writer → Observer
  │   → Normalizer → Governor → Librarian → Auditor → Anti-AI
  │
  ├─ Stage 3 ─ 7 代理同行评审
  │   FieldAnalyst → EIC + R1/R2/R3 + DA 并行 → EditorialSynthesizer
  │
  ├─ Stage 4 ─ 修订 → 复查 → 再修订
  │
  └─ Stage 5 ─ LaTeX 组装 → PDF 编译
```

# Roadmap

Scholarium is under active development. This document outlines our planned direction.

## Short-term (v2.1)

### Citation Verification
- Cross-reference citations against real databases (Semantic Scholar, CrossRef)
- Detect hallucinated or outdated references
- Auto-suggest replacement citations

### Evaluation Metrics
- Automated paper quality scoring (readability, coherence, argument strength)
- Benchmark suite for agent output quality
- Comparison against human-written baselines

### Frontend UX
- Real-time writing progress dashboard
- Interactive mind map editor
- Side-by-side diff view for revisions
- Export to Word (.docx) in addition to LaTeX/PDF

### Documentation
- API reference with OpenAPI/Swagger spec
- Agent development guide (how to create custom agents)
- Deployment guide (Docker, cloud platforms)

## Mid-term (v2.2)

### Plugin System
- Custom agent registration via config
- Third-party LLM provider plugins
- Template marketplace for journal-specific formats

### Multi-language Support
- Full English UI and documentation
- Bilingual paper generation (Chinese-English)
- Support for Japanese, Korean, German academic formats

### Collaboration
- Multi-user editing with conflict resolution
- Role-based access (author, reviewer, editor)
- Shared project workspaces

## Long-term (v3.0)

### Community Ecosystem
- Agent marketplace: share and install community-built agents
- Template contributions for new journals and conferences
- Integration with reference managers (Zotero, Mendeley)

### Advanced Features
- Figure and table auto-generation from data
- Experiment design assistant
- Peer review simulation with configurable reviewer personas
- Plagiarism detection integration

## Contributing to the Roadmap

We welcome input on priorities. To suggest a feature or vote on existing items:

1. Check the [Issues](https://github.com/Gary23333/Scholarium/issues) for existing proposals
2. Open a new issue using the **Feature Request** template
3. Tag it with `roadmap` so we can track community interest

See [CONTRIBUTING.md](CONTRIBUTING.md) for development guidelines.
